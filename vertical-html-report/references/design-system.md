# 디자인 시스템 — 테마·팔레트·색 규칙·타이포그래피

키트가 모든 시각 결정을 내린다. 이 문서는 (1) 테마/팔레트를 고를 때, (2) 회사 브랜드색을 적용할 때 읽는다.

## 1. 테마 6종 (front matter `theme:`)

| 테마 | 주색 | 강조색 | 어울리는 보고서 |
|---|---|---|---|
| `navy` (기본) | #1F3A5F 네이비 | #D9692B 오렌지 | 경영·재무·전략, 대부분의 보고 |
| `blue` | #1E4FB8 블루 | #E8743B | IT·디지털·스타트업, 밝은 톤 |
| `teal` | #0F5F5C 틸 | #E76F51 | ESG·헬스케어·공공 |
| `slate` | #26303E 차콜 | #2F6FE0 블루 | 이사회·감사·법무 등 절제된 문서 |
| `wine` | #6E1E3A 와인 | #C99A2E 골드 | 금융·프리미엄·VIP |
| `forest` | #1F4D3A 포레스트 | #D9822B | 제조·농식품·환경 |

모든 테마의 차트 범주색 8개는 `scripts/check_palette.py --all-themes`로 검증됨:
인접 색 쌍 정상시각 ΔE ≥ 15, 적색맹·녹색맹 시뮬레이션 ΔE ≥ 8 (OKLab×100, Machado 2009).
일부 밝은 색(주황·노랑)은 흰 배경 대비 3:1 미만 → 키트가 값 라벨·데이터 표를 함께 제공해 보완.

## 3. 회사 브랜드색 적용

```
<!--
brand: #0055A4
accent: #F5A623      (선택)
-->
```
- 브랜드색이 주색(제목 번호·요약 박스·차트 1번색·순차 색)이 된다. 나머지 범주색은 테마 것을 유지.
- 적용 전 검증: `python scripts/check_palette.py "#0055A4,#E07B39,#2A9D8F,#C9A227"` → 1번색을 바꾼 팔레트가 FAIL이면 테마를 바꾸거나 1번 인접색과의 구분을 위해 `palette`를 교체.
- 너무 밝은 브랜드색(노랑·연두 등)은 글자색으로 부적합 → `accent`로만 쓰고 `brand`는 진한 색을 쓴다.

## 4. 색의 역할 (섞지 않는다)

| 역할 | 색 | 사용 |
|---|---|---|
| 범주(identity) | c1~c8 | 서로 다른 계열 구분. 순서대로 배정, 순환·임의 생성 금지 |
| 강조(emphasis) | c1 + 회색 | `highlight` — 이야기의 대상만 색, 나머지 회색. 가장 자주 쓸 것 |
| 순차(magnitude) | 주색의 연한→진한 | 히트맵·퍼널·트리 크기 |
| 발산(polarity) | 빨강 계열 ↔ 회색 ↔ 파랑/주색 | 증감·편차(음/양) |
| 상태(status) | good 초록 / warn 주황 / bad 빨강 / info 파랑 | 신호등·배지·증감. 차트 계열색으로 쓰지 않음 |
| IBCS 시나리오 | 실적=진한색, 계획=외곽선, 전망=빗금, 전년=회색 | `role` |

원칙: 한 차트에 의미 있는 색 5개 이하. 색만으로 의미를 전달하지 않는다(라벨·기호 병행).
텍스트는 데이터 색을 입지 않는다(라벨은 검정·회색 계열).

## 5. 타이포그래피

- 서체: **Pretendard**(기본, 한글·숫자 균형이 좋음) → `font: noto`(Google Noto Sans KR) → `font: system`(맑은 고딕/Apple SD 고딕, 사내망 차단 시).
- 크기: 본문 15px, 표 13px, 캡션 12px, 섹션 제목 21px, 보고서 제목 30px. 인쇄 시 10pt 기준으로 일괄 축소.
- 한글 줄바꿈: `word-break: keep-all`(단어 중간에서 끊기지 않음) — 차트 축 라벨도 단어 단위로 줄바꿈.
- 숫자: 표·축은 고정폭 숫자(tabular-nums), KPI 큰 숫자는 비례폭.

## 5-1. 표지

- 기본(`cover: dark`): 종이 상단을 꽉 채우는 테마 주색 3단 그라데이션(진한색→주색→밝은 주색) 밴드 + 오른쪽 점 무늬 질감 + 흰 제목·부제·메타, 상단에 강조색 띠.
- 표지 핵심 수치 `ul.rk-cover-stats`: 3개(최대 4개)의 헤드라인 숫자를 반투명 유리 카드로 표시. 요약·본문에 있는 숫자만 쓴다.
- `brand:`로 밝은 회사색을 지정해도 표지 밴드는 흰 글씨 대비 4.6:1 이상이 되도록 빌드 시 자동으로 어둡게 보정된다.
- 밝은 표지가 필요하면 `cover: light`.

## 5-2. 그라데이션 원칙 (기본 적용)

| 위치 | 그라데이션 |
|---|---|
| 표지 | 진한 주색 → 주색 → 밝은 주색 (118°) + 점 무늬 |
| 섹션 번호 배지 | 진한 주색 → 주색 (135°), 그림자 |
| 섹션 밑줄·요약 상단 띠·의사결정 테두리 | 주색 진함 → 주색 → 주색 옅음 (90°) |
| KPI 상단 선 | 상태(good·warn·bad)가 있으면 상태색 → 옅은 상태색, 없으면 주색 계열. 왼쪽 상태선은 쓰지 않음(색 신호 하나만) |
| 요약·목차·To-Be 바탕 | 옅은 주색 → 흰색 |
| 진척 바 | 상태색의 밝은 톤 → 상태색 |
| 차트 | 막대: 끝으로 갈수록 24% 밝아짐 / 단일 꺾은선·영역: 위 26% → 아래 0% 페이드 / 스파크라인 영역 페이드 |

- **같은 색상 계열 안에서만** 잇는다(주색 진함↔주색↔주색 옅음). 주색→강조색처럼 색상이 다른 두 색을 이으면 가운데가 탁한 갈색·회색이 되므로 금지(예: 남색→주황). 무지개·네온·보라-핑크 그라데이션, 3색 이상 무관한 색 혼합은 금지.
- 상태색(좋음·나쁨)·회색(강조 외 데이터)·계획(외곽선) 막대에는 그라데이션을 넣지 않는다(의미 왜곡 방지).
- 본문에서 CSS로 그라데이션을 직접 만들지 않는다. 끄려면 `style: flat`.

## 6. 레이아웃·인쇄

- 화면: 가운데 960px 종이 + 회색 바탕. 760px 이하에서 1단·여백 축소(모바일).
- 인쇄/PDF: A4 세로, 여백 12~14mm, 차트·카드·표 행은 페이지 경계에서 쪼개지지 않음, 버튼·플로팅 목차·데이터 표 자동 숨김, 배경색 유지(print-color-adjust).
  수동 페이지 나눔: `<div class="rk-pagebreak"></div>`.
- 다크모드는 의도적으로 지원하지 않는다(인쇄·메일 첨부·결재 문서의 일관성).

## 7. 'AI 티' 나는 디자인 피하기

키트를 쓰면 자동으로 피해지지만, 직접 HTML을 덧붙일 때 금지: 보라·핑크·네온·무지개 그라데이션(키트의 같은 계열 그라데이션은 예외 — 기본 적용), 이모지 아이콘, 무거운 그림자,
가운데 정렬 일색, 거대한 히어로 숫자 남발(보고서당 0~1개), 장식용 아이콘, 무지개색 차트, 3D 효과.
